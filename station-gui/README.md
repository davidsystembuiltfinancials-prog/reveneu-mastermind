# ARES Station GUI

Interactive React/Vite sci-fi station map with animated agent sprites and generated pixel-art room assets.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Notes

- Source assets live in `src/assets`.
- Utility scripts in `tools` only perform local image post-processing for included assets.
- No API keys, private tokens, or local generation credentials are required to run this project.
